# クラウドワークス用 プロフィール文・提案文テンプレート（ドラフト）

`[ ]` の箇所はご自身の状況・案件に合わせて書き換えてください。

## プロフィール文

```
生成AI（Claude API）を活用した業務効率化ツールの企画・開発をしています。

日々の業務の中にある「地味だけど時間を取られる作業」を、実際に動くWebツールに落とし込むのが
得意です。直近の実績として、会議の文字起こしを貼り付けるだけで要約・決定事項・タスク一覧を
自動抽出するツールを個人開発しました（ポートフォリオ欄からライブデモをご覧いただけます）。

開発には、GitHub上で「@claude」とメンションするだけでAIが実装を進めるAI駆動の開発フローを
取り入れており、限られた稼働時間でもスピーディに形にすることを心がけています。

【対応可能な範囲】
- 生成AI(Claude API等)を組み込んだ業務効率化ツールの設計・実装
- シンプルな1ページのWebツール、簡易的なAPI連携
- 要件が固まっていない段階からの壁打ち・整理

まずは「こんなことできますか？」というご相談だけでも歓迎です。丁寧なコミュニケーションを
心がけますので、お気軽にお声がけください。
```

## 提案文（応募文）テンプレート

案件に応募する際は、以下をベースに毎回その案件の内容に合わせて書き換えてください
（テンプレート丸ごとのコピペだと熱量が伝わりにくいので、案件文への言及を必ず1〜2文加えてください）。

```
はじめまして、[表示名]と申します。

このたびは「[案件タイトル]」を拝見し、ご提案させていただきました。
[案件文の内容に触れて、理解していることが伝わる一文をここに書く]

生成AI（Claude API）を活用した業務効率化ツールの企画・開発を行っており、
直近では会議の文字起こしを要約・タスク化するツールを個人開発しました。
ポートフォリオからライブデモをご確認いただけますので、技術力・実装の丁寧さの
参考にしていただければと思います。
→ [ポートフォリオ/ライブデモのURL]

本件について、以下のような進め方を想定しています。
1. [ヒアリング・要件整理についての一言]
2. [実装方針の一言]
3. [納期の目安]

ご不明点やすり合わせたい点があれば、遠慮なくご質問ください。
よろしくお願いいたします。
```

### 提案文を書くときのポイント

- 案件文をコピペしたような文面にしない。必ず「その案件固有の内容」に触れる一文を入れる
- ポートフォリオ（議事録自動要約ツール）は「AIを使って実際に手を動かして作れる人」であることの
  証拠として使う。リンクを貼るだけでなく、「このツールでは〇〇という設計上の工夫をしました」と
  一言添えると説得力が増す
- 見積り・納期は、案件文に具体的な条件が書かれていない場合は「ヒアリング後にご提案します」で構わない
- 過去実績（本業由来のもの）には触れない方針を貫く場合は、上記のように
  「個人開発したポートフォリオ作品」としての実績だけで語る
