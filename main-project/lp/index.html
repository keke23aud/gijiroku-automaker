解決しようとした課題

📝

議事録の清書に時間がかかる

録音や文字起こしはできても、要約・整理にいつも時間を取られる。

🙈

タスクの取りこぼしが起きる

「誰が」「何を」「いつまでに」が会話の中に埋もれて、後から見返しづらい。

🔒

会議データを外部サーバーに預けたくない

社内会議の内容を、素性の分からないSaaSに預けるのは避けたい、という設計要件を意識しました。

使い方はシンプルに3ステップ

1

Claude APIキーを入力

お手持ちのAnthropicアカウントのAPIキーを入力します（サーバーには保存されません）。

2

文字起こしを貼り付け

Zoom・Google Meet・Teamsなどの文字起こし結果をそのまま貼り付けます。サンプルデータも用意しています。

3

要約・タスクを確認してコピー

要約、決定事項、担当者・期限つきのタスク一覧が表示されます。ワンクリックでコピーして Slack・Notion・メールに貼り付けられます。

この作品で示せること

ご依頼を検討いただく際の判断材料として、実装の背景にある考え方をまとめました

🤖

Claude APIを使った要約・情報抽出の実装

プロンプト設計だけでなく、JSON形式での構造化出力・パース失敗時のフォールバック・ エラーメッセージの日本語化まで、実運用を意識して作り込んでいます。

⚙️

Claude Code + GitHub Actionsを使ったAI駆動の開発フロー

GitHub Issueに要件を書いて「@claude」とメンションするだけで、AIが非同期でPull Requestを 作成する開発体制を構築しています。少ない稼働時間でも開発を前に進められる、 AI活用時代の開発スタイルです。

🔐

データを預からない設計（プライバシー配慮）

ユーザーのAPIキーや会議データがサーバーを経由しない構成にすることで、 運用コストとプライバシーリスクの両方を最小化する設計を選びました。

🎨

単一HTMLで完結するフロントエンド実装

フレームワークに頼らずVanilla JS + CSSのみで、ライト/ダーク両対応のUIを実装しています。

よくある質問

Claude APIキーはどこで取得できますか？

Anthropic Consoleでアカウントを作成し、APIキーを発行してください。利用料はAnthropicへの従量課金となります（このデモの利用自体は無料です）。

入力した会議の内容は保存されますか？

いいえ。会議テキストとAPIキーは、お使いのブラウザからClaude APIへ直接送信されるだけで、開発者側のサーバーには一切保存されません。

コードは公開されていますか？

はい。GitHubリポジトリで公開しています。Claude Code・GitHub Actionsを使った開発フローも含めて、実装の詳細やコミット履歴をご確認いただけます。

似たようなツールを自分の業務用に作ってもらえますか？

はい、対応可能です。上記の「お仕事のご相談」からご連絡ください。
